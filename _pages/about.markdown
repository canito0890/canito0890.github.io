## Hello There!

I'm **Joel Cano**, a full stack developer with 15+ years of hands-on experience building
web applications. I spend my days in Ruby on Rails, JavaScript, and PostgreSQL, and I care
most about the part of the job where a hard problem turns into code that other people can
read, extend, and trust.

## What I Do

I build and maintain production web applications end to end — data model, backend, API,
frontend, and the infrastructure they run on. Most of my recent work has been in the
telecom space: an MVNO CRM and its supporting APIs, a PBX built on Asterisk, and a telco
CRM, all Rails on the backend with Ember.js front ends.

The through-line across all of it is long-lived systems. These are applications that
teams depend on daily and that I've kept healthy for years, which is where I've learned
the most about schema design, API boundaries, and how much future pain a clear
abstraction saves.
